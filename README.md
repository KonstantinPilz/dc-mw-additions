# Data-center capacity additions by country, 2022–2026

Interactive visualization of annual data-center IT (critical) MW additions for 22 countries, 2022–2026E. Medians; built by Konstantin's Claude research team (nine codex Sol researchers + nine-Sol red team), 2026-08-12.

Live: https://konstantinpilz.github.io/dc-mw-additions/

- `docs/index.html` — self-contained page (D3 via CDN), log/linear, annual/cumulative, top-N toggles, per-cell sourced reasoning in tooltips.
- `docs/data.json` — the dataset (red-team adjusted, 19 of 110 rows).
- Source research: `~/research/dc-mw-additions/` on the research VM (definition, per-country memos, red-team reports).

Page carries `noindex, nofollow`.
